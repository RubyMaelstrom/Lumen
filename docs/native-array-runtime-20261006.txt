Local array operations — 6 October 2026
======================================

The ARM64 template tier now reads a local array receiver and numeric index
without first manufacturing temporary owning operand-stack values. This removes
repeated object/value runtime work in the two hot array-iteration regions of
the React-derived reducer fixture. The standalone candidate takes 6.6% less
time there. Smaller application gains and all measured regression gates pass;
the source experiment is retained. This remains far short of the requested
8–10x overall improvement, and the investigation continues.

Implementation and boundaries
-----------------------------

Recognize LoadLocal(receiver), LoadLocal(key), GetElem and
LoadLocal(key), LoadLocal(receiver), In inside a numeric region. The canonical
local remains the receiver owner; a numeric key home can supply the index
directly. Successful own-element paths preserve the other numeric homes. The
older two-operation GetElemLocal path uses the same cold-miss discipline.

Live layout, exotic, descriptor, bounds and index guards remain in place.
The In shortcut answers only true for an existing own dense element. Holes,
inherited properties, proxies, key coercion, unusual indices and uncertain
receivers replay the original operations after publishing numeric homes.
The helper may execute author code, so the return reloads and revalidates the
homes. A failed reload resumes after the consumed operations without flushing
stale registers over canonical slots changed by reentry. Numeric-home receiver
slots are excluded. No collector or default representation changes are made.

Six new fixtures exercise actual three-operation/D-register admission using
test-only counters, plus holes, inherited getters, prototype mutation, GC,
proxy traps, coercion order, special keys, thrown values and TDZ behavior.
Counters compile out of production. The x86-64 emitter is unchanged.

Disposition and continuation
----------------------------

A separate PropertyKey/Reflect/RegExp experiment is parked and absent from
this source. Its few-percent gains did not justify a reproducible startup-RSS
regression: all 80 fixed pairs pooled gave ratio 1.04225, interval
[1.02591, 1.05462]. Its patch, binaries and passing semantic checks remain
under benchmark-results/object-runtime-followup-20261005-93yqcva9/. It was
not accepted or committed. The array experiment was rebuilt independently.

Next candidates address repeated local-state publication around lexical slot
clears and warmed property reads that retain generic probes. They need their
own correctness and performance evidence. The current result does not settle
the object/value architecture investigation.
