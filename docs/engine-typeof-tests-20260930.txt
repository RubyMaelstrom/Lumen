Direct typeof literal tests — 30 September 2026
=============================================

The solver's diagnostic helper trace showed 1,225,799 executions of one typeof
site. It was a compiler-generated Number guard before an integer switch tree:
LoadLocal, Typeof, Const("number"), StrictEq. The typeof operation allocated a
string just to compare its category. That guard now uses TypeofIs(Number).
Literal comparisons with typeof also use TypeofIs, in either operand order,
for ==, !=, === and !==. Both comparison operands are strings, so loose equality
needs no conversion. Unknown literals still evaluate the operand and preserve
its effects/errors before returning the comparison result.

The VM and checked native helper return Boolean directly. The shared ARM64
operation emitter classifies scalar execution words and releases non-final
owners without allocating a result string. Object tests needing [[Call]] or
[[IsHTMLDDA]], BigInt owners and last-owned references retain checked handling.
Unresolved identifier comparisons retain TypeofName; local reads preserve TDZ.
The optional optimizer records the Boolean category and preserved-local effect.
Unsupported native platforms keep the checked operation.

An earlier span-only draft missed copies of operations emitted inside SSA
regions. Its native-helper assertion failed; that draft is preserved locally
as v1-native-span.patch and was not measured or committed. Making the operation
explicit in bytecode lets baseline and region emission use the same lowering.

Validation: all 1,578 engine library tests pass, including native-helper counts,
scalar categories, NaN/signed zero/infinities, unknown literals, getter throws,
operand reversal, revoked callable proxies, HTMLDDA and TDZ in all three tiers.
The existing integer-switch regression covers non-coercion, strict misses,
duplicates, fallthrough, defaults and lexical instantiation in all tiers.
Workspace all-target checking, strict engine all-target Clippy and optional
optimizing-jit all-target checking pass. No x64 execution, wasm build, new
Test262 or optional-backend execution result is claimed.
