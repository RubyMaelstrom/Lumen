Array HasProperty/Get fusion — 6 October 2026
============================================

The ARM64 template tier now combines the guarded own-element HasProperty/Get
sequence in self-hosted array iteration. The React-derived reducer takes 6.2%
less time than the compact-Intl baseline. This is a further component gain,
not a measured cumulative speedup or the requested 8–10x overall improvement.

The fast path removes repeated receiver/index/descriptor checks and temporary
owners across the exact In/branch/TDZ/Get/Store sequence. It admits only existing
own data elements with an exact numeric index. Holes, inherited accessors,
proxies, key coercion and unusual indices retain the checked path. CFG checks
exclude interior entries, handler/resume roots and incompatible numeric homes.
TDZ writes retain ordered owner releases. If either release might destroy an
object, including two locals sharing its final two owners, execution falls
back before the sequence. No borrowed pointer survives a release. This keeps
host-destructor reentry and callback mutation observable in their original order.

The accompanying local-effect classification keeps private numeric homes live
across In/Abstract operations and clears only a TDZ target that is not a numeric
home. Heap facts are still invalidated; numeric TDZ targets retain full recovery.

The complete matrix also includes eleven renderer-shaped kernels, startup and

The original six WebGL peak-RSS pairs crossed the provisional regression gate:
1.03952 [1.00760, 1.08563]. A predeclared twenty-pair confirmation measured
.99343 [.96436, 1.02546]; all 26 pairs give 1.00595 [.97334, 1.03825]. The
separate twelve-pair identical-byte control has no material gate crossing in
either direction. Its system-CPU ratio is unavailable because a baseline

original flags or previous artifact-confounded results were discarded; no
A/A subtraction or retrospective noise threshold was used.

Fresh non-reflink copies were prepared once, with hashes checked and allocation
metadata recorded. Some filefrag extents were still delalloc/unknown_loc;
physical allocation identity is not claimed. This qualification applies to
the matched runs, and the separate A/A observations remain in the record.

Separate diagnostic runs show unchanged compile and GC counts. React native
code falls from 276404 to 268620 bytes; all five application/control code totals
fall slightly. These single diagnostic runs do not establish compile-time or
GC-pause improvements. The executable grows from 17346000 to 17369936 bytes.
This change makes no general memory-saving claim.
