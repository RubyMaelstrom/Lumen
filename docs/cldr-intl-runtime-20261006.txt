Compact CLDR number and display-name tables — 2026-10-06

NumberFormat and DisplayNames now use deduplicated static text blobs, u16
string IDs, and u32 offset/length directories. This extends the accepted date
table representation. Public lookup results remain borrowed static strings;
table contents, ordering, fallback behavior and locale coverage are unchanged.
There is no runtime allocation, unsafe code, dependency or locale-data update
in this storage change.

Both generators pin CLDR JSON 48.0.0 at
4d06be52b51bb2f75688d0abe55c52a66afed790. Input manifests preserve URL, status
and content hashes, including five expected missing DisplayNames inputs.
The old generators first reproduced the prior generated sources. Exhaustive
comparison preserved all 53 number tables / 13,743 records and all 218
display-name tables / 27,743 records plus 22 locale patterns. The number blob
has 11,132 distinct strings in 260,533 bytes; the display-name blob has 24,546
strings in 431,315 bytes. Tests validate every directory entry and table order.
